# Grouped Expenses - User Guide

## What's New? 🎉

Your expense tracker now automatically groups multiple entries of the same type together, making it easier to see your spending patterns at a glance!

## How It Works

### Before (Old View)
```
Food & Groceries    ₹300
Food & Groceries    ₹250
Food & Groceries    ₹200
Transportation      ₹150
Transportation      ₹100
```

### After (New Grouped View)
```
Food & Groceries [3×]    ₹750
Transportation [2×]      ₹250
```

Much cleaner! 🎯

## Using the Grouped View

### 1. **Viewing Your Entries**

When you log multiple expenses of the same type, they automatically group together:

- **Single Entry**: Shows time and comment preview
  ```
  Food & Groceries          ₹250
    10:30 · Bought vegetables
  ```

- **Multiple Entries**: Shows count badge and total
  ```
  Food & Groceries [3×]     ₹750
    3 entries · Tap to view details
  ```

### 2. **Viewing Details**

**Tap on any entry** to see full details:

#### For Single Entries:
- Full amount, limit, and savings
- Complete comment
- Time logged
- Edit and Delete buttons

#### For Grouped Entries:
- **Summary at top**: Total amount, limit, and total savings
- **List of all entries**: Each entry shown separately with:
  - Individual amount and savings
  - Time logged
  - Full comment
  - Edit and Delete buttons for each

### 3. **Quick Actions**

#### Single Entries:
- **Edit button** (pencil icon): Modify the entry
- **Delete button** (trash icon): Remove the entry

#### Grouped Entries:
- **Tap the group**: Opens detail view
- **In detail view**: Edit or delete individual entries

### 4. **Understanding the Display**

Each entry/group shows:

| Element | Meaning |
|---------|---------|
| **Category Icon** | Visual identifier for expense type |
| **Count Badge** (e.g., 3×) | Number of entries in this group |
| **Amount** | Total spent (or individual amount) |
| **Limit** | Your daily budget for this category |
| **Savings** | How much under/over budget you are |
| **Color Stripe** | Left edge colored by category |

### 5. **Color Indicators**

- **Green Savings** (+₹50): You're under budget! 🎉
- **Red Savings** (-₹50): You're over budget ⚠️
- **Category Colors**: Each expense type has its own color

## Tips & Tricks

### 💡 Tip 1: Quick Overview
The description now shows: "5 logged · 3 categories"
- **5 logged**: Total number of individual entries
- **3 categories**: Number of different expense types

### 💡 Tip 2: Highest Spending First
Groups are automatically sorted by total amount, so you can quickly see where most of your money is going.

### 💡 Tip 3: Detailed Comments
Long comments are fully visible in the detail popup with scrolling support.

### 💡 Tip 4: Date Navigation
Use the date picker to view past days - grouping works for any date!

### 💡 Tip 5: Edit from Detail View
When viewing grouped entries, you can edit or delete individual entries without closing the popup.

## Frequently Asked Questions

### Q: Can I still edit individual entries?
**A:** Yes! Tap on the group to see all entries, then use the edit button on any individual entry.

### Q: How do I delete a specific entry from a group?
**A:** Tap the group to open details, then tap the delete button (trash icon) next to the entry you want to remove.

### Q: What if I only have one entry per category?
**A:** Single entries display normally with quick edit/delete buttons - no grouping UI appears.

### Q: Can I see entries from previous days?
**A:** Yes! Use the date picker at the top of "Today's Entries" section. Grouping works for any date.

### Q: Why are some groups at the top?
**A:** Groups are sorted by total amount spent (highest first), helping you identify your biggest expenses.

### Q: What does the count badge mean?
**A:** The badge (e.g., "3×") shows how many individual entries are in that group.
