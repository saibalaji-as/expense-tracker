# Overspending Alert - User Guide

## What's New? 🎉

Your expense tracker now helps you learn from past spending! If you overspent in any category last month, you'll get a friendly reminder when logging expenses in that category this month.

## How It Works

### The Smart Alert

When you select a category you overspent in last month, you'll see:

```
┌─────────────────────────────────────────────┐
│ ⚠️  Budget Alert: Utilities            [×] │
│                                             │
│ You overspent on Utilities last month by   │
│ ₹2,290.                                     │
│                                             │
│ Last Month Spent: ₹5,190                   │
│ Monthly Limit: ₹2,900                      │
│                                             │
│ 💡 Consider if this expense is necessary   │
│    to avoid overspending again this month. │
└─────────────────────────────────────────────┘
```

### What It Tells You

1. **Category Name**: Which category you overspent in
2. **Overspent Amount**: How much you went over budget
3. **Last Month's Total**: What you actually spent
4. **Monthly Limit**: What your budget was
5. **Helpful Tip**: Gentle reminder to think twice

## Real-World Example

### Your Gas Stove Purchase

**April (Last Month)**:
- You bought a gas stove for ₹5,190
- Your Utilities budget was ₹2,900/month
- You overspent by ₹2,290

**May (This Month)**:
When you select "Utilities" to log an expense:

```
⚠️ Budget Alert: Utilities

You overspent on Utilities last month by ₹2,290.

Last Month Spent: ₹5,190  •  Monthly Limit: ₹2,900

💡 Consider if this expense is necessary to avoid 
   overspending again this month.
```

**Your Thought Process**:
- "Oh right, I bought that expensive stove last month"
- "This is just my regular ₹200 electricity bill"
- "That's fine, I'll proceed"

**Action**: Dismiss the alert and log your ₹200 expense ✅

## When Alerts Appear

### ✅ You'll See an Alert When:
- You overspent in a category last month
- You select that category this month
- You haven't dismissed it yet this session

### ❌ You Won't See an Alert When:
- You stayed within budget last month
- You're logging in a different category
- You already dismissed it this session
- No data exists for last month

## Using the Alert

### Option 1: Proceed with Expense
```
1. Read the alert
2. Decide the expense is necessary
3. Click [×] to dismiss
4. Continue logging your expense
```

**When to Choose This**:
- Regular recurring expenses (bills, rent)
- Necessary purchases
- One-time overspending last month
- Small expense within this month's budget

### Option 2: Reconsider
```
1. Read the alert
2. Realize you might overspend again
3. Click [×] to dismiss
4. Change category or cancel entry
```

**When to Choose This**:
- Discretionary spending
- Can be postponed
- Pattern of overspending
- Already spent a lot this month

### Option 3: Change Category
```
1. Read the alert
2. Realize expense fits better elsewhere
3. Select different category
4. Log under correct category
```

**When to Choose This**:
- Misclassified expense
- Better category available
- Avoid overspending in warned category

## Understanding the Alert

### The Numbers

```
Last Month Spent: ₹5,190
Monthly Limit: ₹2,900
Overspent: ₹2,290
```

**What This Means**:
- You had a budget of ₹2,900 for the month
- You actually spent ₹5,190
- You went over by ₹2,290

### The Warning Level

**Orange/Amber Color** = ⚠️ Warning (not error)
- Not blocking you
- Just a friendly reminder
- You can still proceed
- Your choice matters

## Tips for Success

### 💡 Tip 1: Think Before Dismissing
Don't automatically dismiss the alert. Take a moment to:
- Read the numbers
- Consider your current month's spending
- Decide if the expense is necessary

### 💡 Tip 2: Track Patterns
If you see the same alert multiple months:
- You might have a spending pattern
- Consider adjusting your budget
- Or reduce spending in that category

### 💡 Tip 3: One-Time vs Recurring
Distinguish between:
- **One-time**: Large purchases (appliances, furniture)
- **Recurring**: Regular overspending (dining, entertainment)

One-time is okay. Recurring needs attention.

### 💡 Tip 4: Use Comments
When logging expenses, add comments:
- "Emergency repair"
- "One-time purchase"
- "Birthday celebration"

This helps you remember context later.

### 💡 Tip 5: Review Monthly
At month-end, review which categories triggered alerts:
- Were they justified?
- Can you reduce next month?
- Should you adjust budgets?

## Frequently Asked Questions

### Q: Will this block me from logging expenses?
**A:** No! It's just a reminder. You can always dismiss it and proceed.

### Q: How often will I see the alert?
**A:** Once per category per session. If you dismiss it, it won't show again until you close and reopen the app.

### Q: What if I overspent because of an emergency?
**A:** That's fine! The alert is just informational. You can dismiss it and proceed with your regular expenses.

### Q: Can I turn off these alerts?
**A:** Currently no, but they're designed to be non-intrusive. You can dismiss them with one click.

### Q: What if I don't have data from last month?
**A:** No alert will show. The system only warns when it has previous month data.

### Q: Does this affect my budget for this month?
**A:** No. Each month has its own budget. The alert is just a reminder about last month.

### Q: Will it remember I dismissed it?
**A:** Yes, for the current session. When you close and reopen the app, it will show again as a gentle reminder.

### Q: What if I overspent in multiple categories?
**A:** You'll see an alert for each overspent category when you select it.
