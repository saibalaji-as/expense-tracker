# FCM Notification API Reference

## Base URL
```
https://your-site.netlify.app/.netlify/functions
```

---

## Endpoints

### 1. Register Token

**Endpoint:** `/register-token`  
**Method:** `POST`  
**Description:** Register a new FCM token for a user

**Request:**
```json
{
  "userId": "user_1704067200000_k3j9x2m1p",
  "fcmToken": "fcm_token_abc123...",
  "intervalMinutes": 60,
  "timestamp": 1704067200000
}
```

**Response (Success):**
```json
{
  "success": true,
  "message": "Token registered successfully",
  "userId": "user_1704067200000_k3j9x2m1p"
}
```

**Response (Error):**
```json
{
  "error": "Missing required fields",
  "required": ["userId", "fcmToken", "intervalMinutes"]
}
```

**Status Codes:**
- `200` - Success
- `400` - Bad request (missing/invalid fields)
- `500` - Internal server error

---

### 2. Send Reminders

**Endpoint:** `/send-reminders`  
**Method:** `GET` or `POST`  
**Description:** Send notifications to all users who are due (triggered by cron job)

**Request:** No body required

**Response:**
```json
{
  "success": true,
  "timestamp": "2024-01-01T12:00:00.000Z",
  "totalUsers": 50,
  "sent": 12,
  "skipped": 38,
  "errors": 0,
  "message": "Processed 50 users: 12 sent, 38 skipped, 0 errors"
}
```

**Status Codes:**
- `200` - Success (even if no notifications sent)
- `500` - Internal server error

---

### 3. Update Preferences

**Endpoint:** `/update-preferences`  
**Method:** `POST`  
**Description:** Update notification interval for a user

**Request:**
```json
{
  "userId": "user_1704067200000_k3j9x2m1p",
  "intervalMinutes": 120
}
```

**Response (Success):**
```json
{
  "success": true,
  "message": "Preferences updated successfully",
  "userId": "user_1704067200000_k3j9x2m1p",
  "intervalMinutes": 120
}
```

**Response (Error - User Not Found):**
```json
{
  "error": "User not found",
  "message": "Please enable notifications first"
}
```

**Status Codes:**
- `200` - Success
- `400` - Bad request (missing/invalid fields)
- `404` - User not found
- `500` - Internal server error

---

### 4. Unregister Token

**Endpoint:** `/unregister-token`  
**Method:** `POST`  
**Description:** Remove user from notification system

**Request:**
```json
{
  "userId": "user_1704067200000_k3j9x2m1p"
}
```

**Response:**
```json
{
  "success": true,
  "message": "Token unregistered successfully",
  "userId": "user_1704067200000_k3j9x2m1p"
}
```

**Status Codes:**
- `200` - Success (even if user doesn't exist)
- `400` - Bad request (missing userId)
- `500` - Internal server error

---

## Validation Rules

### Interval Minutes
- **Minimum:** 15 minutes
- **Maximum:** 480 minutes (8 hours)
- **Default:** 60 minutes

### User ID Format
- Generated by frontend: `user_<timestamp>_<random>`
- Example: `user_1704067200000_k3j9x2m1p`
- Stored in localStorage: `pf_user_id`

### FCM Token
- Generated by Firebase SDK
- Format: Long alphanumeric string
- Example: `fcm_token_abc123def456...`

---

## Error Codes

| Status | Error | Description |
|--------|-------|-------------|
| 400 | Missing required fields | Request body missing userId, fcmToken, or intervalMinutes |
| 400 | Invalid interval | Interval not between 15-480 minutes |
| 404 | User not found | User doesn't exist in database |
| 405 | Method Not Allowed | Wrong HTTP method used |
| 500 | Internal server error | Server-side error (check logs) |

## Security

### CORS
All endpoints support CORS for cross-origin requests from your PWA.

### Authentication
Currently no authentication required (user ID acts as identifier).

**Future Enhancement:** Add API key or JWT authentication for production.

### Environment Variables
Backend credentials stored securely in Netlify environment variables:
- `FIREBASE_PROJECT_ID`
- `FIREBASE_CLIENT_EMAIL`
- `FIREBASE_PRIVATE_KEY`

## Troubleshooting

### "Firebase Admin initialization failed"
- Check environment variables in Netlify Dashboard
- Verify private key format (includes `\n` characters)
- Redeploy after adding environment variables

### "Invalid registration token"
- Token automatically removed from database
- User needs to re-enable notifications

### "User not found"
- User hasn't registered yet
- Call `/register-token` first

### Function timeout
- Check Firestore query performance
- Verify Firebase Admin SDK initialization
- Review function logs for errors
