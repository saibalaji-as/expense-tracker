# Backdate Expense Entry - User Guide

## What's New? 🎉

You can now log expenses for **previous dates**, not just today! Forgot to log yesterday's coffee? No problem! Want to backfill last week's expenses? Easy!

## How to Use

### Logging an Expense for Today (Default)

1. Open the expense entry form
2. The date is automatically set to **today**
3. Select category, enter amount, add comment
4. Click "Log [Category]"
5. Done! ✅

### Logging an Expense for a Previous Date

1. Open the expense entry form
2. **Click on the date picker** (shows today's date by default)
3. **Select the date** when the expense actually occurred
4. Enter the expense details (category, amount, comment)
5. Click "Log [Category]"
6. Your expense is logged with the correct date! ✅

### Quick Reset to Today

If you accidentally changed the date and want to go back to today:

1. Look for the **"Today"** button next to the date picker
2. Click it
3. Date resets to today instantly! ✅

## Common Scenarios

### Scenario 1: Forgot Yesterday's Lunch

**Problem**: You forgot to log yesterday's ₹150 lunch expense.

**Solution**:
1. Open expense entry form
2. Click date picker
3. Select yesterday's date
4. Select "Dining Out"
5. Enter ₹150
6. Add comment: "Lunch at cafe"
7. Click "Log Dining Out"

**Result**: Expense appears on yesterday's date! ✅

### Scenario 2: Backfilling Last Week

**Problem**: You were on vacation and didn't log expenses for a week.

**Solution**:
1. For each expense:
   - Select the date it occurred
   - Enter category and amount
   - Add comment if needed
   - Submit
2. Repeat for all expenses

**Result**: Complete expense history for the week! ✅

### Scenario 3: Wrong Date Entry

**Problem**: You logged today's expense but it was actually yesterday's.

**Solution**:
1. Find the entry in "Today's Entries"
2. Click **Edit** button
3. Change the date to yesterday
4. Click "Update [Category]"

**Result**: Entry moves to correct date! ✅

### Scenario 4: Multiple Expenses Same Day

**Problem**: You want to log 3 expenses from 2 days ago.

**Solution**:
1. Select the date (2 days ago)
2. Log first expense
3. Date resets to today after submit
4. Select the same date again
5. Log second expense
6. Repeat for third expense

**Tip**: The date resets to today after each entry, so you'll need to select the past date each time.

## Tips & Tricks

### 💡 Tip 1: Use Comments for Context
When logging old expenses, add comments to remember details:
- "Grocery shopping - weekly"
- "Uber to airport"
- "Birthday gift for mom"

### 💡 Tip 2: Check the Date Before Submit
Always verify the date is correct before clicking "Log". The date picker shows the selected date clearly.

### 💡 Tip 3: Navigate to View
After logging a backdated expense:
1. Use the date picker in "Today's Entries" section
2. Navigate to that date
3. Verify your entry appears correctly

### 💡 Tip 4: Batch Entry
If logging multiple expenses for the same date:
- Keep the date picker open in another tab for reference
- Or write down the date
- Select it for each entry

### 💡 Tip 5: Today is Default
For most entries (today's expenses), you don't need to touch the date picker at all. It defaults to today!

## Important Notes

### ✅ What You Can Do
- Log expenses for **any past date**
- Edit an entry's date
- View backdated entries by navigating to that date
- Log multiple entries for the same past date

### ❌ What You Cannot Do
- Log expenses for **future dates** (date picker blocks this)
- The date picker's maximum date is always today

### 📊 How It Affects Your Budget
- Backdated expenses count toward **that date's budget**, not today's
- Your "Today" summary only shows today's expenses
- Navigate to past dates to see their totals

## Frequently Asked Questions

### Q: Can I log expenses from last month?
**A:** Yes! You can select any past date, including dates from previous months or even years.

### Q: Can I log expenses for tomorrow?
**A:** No. The date picker only allows dates up to and including today. You cannot log future expenses.

### Q: What happens after I submit a backdated expense?
**A:** The form resets and the date picker goes back to today's date, ready for your next entry.

### Q: Can I edit the date of an existing entry?
**A:** Yes! Click edit on any entry, change the date, and update. The entry will move to the new date.

### Q: Will backdated entries affect today's budget?
**A:** No. Each date has its own budget. Backdated entries count toward that date's budget, not today's.

### Q: How do I see my backdated entries?
**A:** Use the date picker in the "Today's Entries" section to navigate to that date.

### Q: Can I log multiple expenses for the same past date?
**A:** Yes! Just select the date each time you log an entry. The date resets to today after each submission.

### Q: What if I'm not sure of the exact date?
**A:** Choose your best estimate. You can always edit the entry later to correct the date.

## Troubleshooting

### Issue: Date picker not opening
**Solution**: Click directly on the date value or the calendar icon

### Issue: Can't select a date
**Solution**: Make sure the date is not in the future. Only past and present dates are allowed.

### Issue: Date keeps resetting
**Solution**: This is normal behavior. After submitting an entry, the date resets to today for convenience.

### Issue: Backdated entry not showing
**Solution**: Navigate to that date using the date picker in "Today's Entries" section to view it.

### Issue: Wrong date after edit
**Solution**: When editing, check the date picker shows the correct date before updating.
